# 输入设备与配置归属

工作台以**当前选中的真实输入设备**为配置对象。连接多只手柄时，在控制器库选择要使用的那一只；概览、手柄映射、键鼠映射与设备设置会一起切换，只显示这只设备的配置。

## 显示与保存

- **设备配置独立**：按键映射、输入阈值、右摇杆鼠标参数，以及灯光、振动、触摸板、长按时长、截图触觉和设备隐身偏好均归属对应设备。两只同型号手柄也使用各自的配置。
- **按硬件能力显示**：按键和轴以驱动实际报告为准；设备没有灯光、触摸板或振动能力时，不显示对应设置。配置中曾经保存的功能不会被当作硬件能力。
- **没有连接设备**：显示通用 XInput 按键与公共配置，便于查看和编辑；设备专属配置及硬件操作在重新识别对应设备后出现。公共配置与真实设备的配置分别保存。
- **应用设置共享**：界面语言、截图目录与捕获方式、快门声音、回放录像、后台服务、登录启动等仍是整个应用的设置。

## 设备身份

驱动能提供序列号或稳定设备路径时，程序据此识别物理设备，重启后可继续关联对应配置。连接方式或驱动改变而导致身份变化时，可能会识别为另一设备。

没有稳定身份的设备使用本次运行的会话身份，仍能区分同时接入的同型号手柄，但不能保证重启后自动恢复到同一配置。

## 已有配置

首次升级设备归属规则时，原始配置文件会原样备份为同目录下的 `studio.before-device-profiles-v1.json`。旧映射和未使用的数据保留在配置中；不属于当前设备的预设不出现在选择列表里。原有型号级配置首次匹配设备后归属该设备，之后连接的同型号手柄使用独立配置。
