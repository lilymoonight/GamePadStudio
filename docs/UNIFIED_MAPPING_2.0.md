# 2.0 按键逻辑与验收约定

本文记录当前实现，优先于旧版 DESIGN.md 中尚未完成的设计设想。

## 唯一数据与执行入口

- 当前预设只有 `active_profile`。概览、手柄映射、键鼠页和后台读写同一份 `profiles`，不存在另一个“已启用键鼠方案”。
- SDL 位置编号是唯一输入标识。Xbox 的 A/B/X/Y 和 PlayStation 的 ×/○/□/△ 使用各自标签；标签不参与按键匹配。LT/RT、左右摇杆方向、左摇杆推满也可显式绑定。
- `InputNormalizer → GestureEngine → MappingRuntime` 是唯一执行链。游戏预设只有数据，没有专属引擎、隐藏换键或另行触发的组合键。
- 手柄页、键帽和映射列表使用同一个 `BindingDialog`。可手动选择最多四个输入，或录入同时按住的组合。录入收集同时出现的按键，不把依次按下的按键拼成组合。
- 背景进程执行输入。管理窗口只显示后台的物理输入、命中的绑定、实际输出和最近动作。映射窗口聚焦时可开启“安全试按”：同一运行实例继续判断手势与回显，但不向系统发送输出；焦点离开或窗口关闭后解除，租约最多一秒自动过期，仍按住的输入需松开再按。独立测试模式复用同一个执行类。

## 手势规则

1. 组合键顺序不限。重叠时优先选择包含更多按键的组合；同等长度按规范化标识稳定排序。已消费的输入需要释放后才能作为单键再次触发。
2. 短按普通动作在松开时执行。只绑定“按住”时立即按下，松开释放；若同时参与更长组合，则等待 80 毫秒。
3. 设置了长按动作时，先等待长按阈值（默认 0.65 秒，可在同一编辑器逐项修改）。提前松开仅执行短按；达到阈值仅执行一次长按，之后松开不补发短按。
4. 短按和长按均能绑定“按住键盘”或“按住鼠标”。长按输出保持到组合任一组件松开。等待长按时不会提前发出短按的按住输出；短按最终用一个短脉冲执行。
5. 后加入的组合取消并释放已启动的单键按住输出。已经向系统发出的输入无法撤销，因此需要组合的单键带有上述 80 毫秒等待窗口。
6. 快捷键支持 Ctrl+Shift+S，也支持 W+Space 等多个普通键。键盘和鼠标输出有持有计数；一个映射释放时不会打断另一个映射仍持有的按键。快捷键脉冲由下一轮输入时钟释放，不在轮询线程中睡眠。
7. 暂停、断线、切换设备、修改映射、切换预设、关闭进程均释放输出。恢复时仍按着的输入不补触发，须松开再按。测试保护和编辑器租约同样遵守此规则。
8. 摇杆/扳机使用统一阈值与滞回；录入和执行使用同一归一化器。左摇杆推满的辅助绑定可手动选择，录入方向时不重复加入“推满”。

双击、宏序列、虚拟 Xbox 输出和驱动层屏蔽不属于本次实现。映射 `none` 表示本软件不产生动作，并不吞掉游戏的原始手柄输入。设备隐身仍依赖 HidHide，当前软件保留 Xbox 隐身不可用的限制。

## 配置迁移与写入

首次升级保存 `studio.before-unified-mapping-v2.json`。旧键鼠方案转为普通预设，保留所有自定义按钮、组合、鼠标参数；隐式 WASD、推满 Shift 和右摇杆鼠标变为可见配置。原生手柄预设保留。旧方案中肩键的“短按轮盘、长按静默”转成显式“不触发”长按绑定，并保留原来的按住时长。

旧全局键鼠方案若启用，升级后选择其对应预设，并将已有设备关联到该预设，以延续原来的实际输出。之后每个设备的预设选择独立保存。原来基于前台窗口猜测并偷偷把 A/Space 改成鼠标的行为取消；目标动作始终与编辑器中显示的一致，可明确切换桌面预设。

UI 的映射修改经后台验证、保存并返回权威配置；配置写入按旧值/编辑值/磁盘最新值合并，避免设置页把后台刚修改的映射覆盖。关闭窗口后后台按同一配置继续工作。

## 验证

### 2.0.1 输入故障保护

暂停状态写入配置，退出、重启、升级后继续保持暂停，只有显式恢复才重新启用。重复启动后台不再终止仍然存活的输入进程；安装时清理旧产品名的重复启动项，静默安装不再自动运行后台。

输出按键在发送前登记。Windows 拒绝全部或部分输入时尝试释放已登记的按键；重试失败不再视为成功。释放逐键执行，一处失败仍继续释放其他键和鼠标，并保留失败记录供后续重试。退出后台首先释放输入，再等待录像和其他资源关闭。

本机故障中实测左 Alt 在进程退出后仍为按下，单独发送释放后系统状态清零，用户确认实体键盘恢复。原始故障缺少输出调用记录，不能确定这一次残留的具体产生路径；上述保护修复由模拟底层部分失败、权限拒绝、释放失败、重复启动和暂停重启测试验证。

自动测试覆盖同一输入的短按/长按互斥、四种组合顺序、三键优先级、摇杆与扳机滞回、共享修饰键和鼠标释放、短脉冲回显、暂停/断线/换配置、旧方案迁移、并发设置保存、共用编辑器和键帽状态。真实硬件是否触发 Windows Game Bar 等外部程序仍需实机观察，不能用模拟输入测试代替。
